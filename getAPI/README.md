# getAPI フォルダの説明

このフォルダは、YouTube Data APIを利用した動画情報取得・前処理・データ生成のための各種スクリプトを格納しています。

## ファイル一覧と役割

### api.py
YouTube Data APIの認証・リクエスト・レスポンス処理をまとめたモジュール。APIキー管理やAPI呼び出しのラッパー関数を提供します。

### get_details.py
YouTube動画IDリストから、API経由で詳細情報（タイトル、説明、再生数、公開日など）を取得し、データファイル（JSON等）に保存するスクリプトです。

### main.py
getAPIフォルダの各種処理を統括するメインスクリプト。バッチ実行や一連のデータ取得・前処理フローを制御します。

### preprocessing.py
取得した動画データの前処理（特徴量抽出、埋め込み生成、カテゴリ・チャンネルのワンホット化など）を行い、機械学習用のデータセット（CSV/JSON）を生成するスクリプトです。

### __pycache__/
Pythonのバイトコードキャッシュ（自動生成）。通常は編集不要です。

---

このフォルダのスクリプト群は、YouTube動画データの収集・加工・機械学習用データセット生成の自動化を目的としています。
