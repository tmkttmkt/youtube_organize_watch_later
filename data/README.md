# data フォルダのファイル説明

このフォルダは、YouTube動画管理・分類・機械学習のための各種データファイルを格納しています。

## ファイル一覧と説明

### details_data.json
YouTube動画の詳細情報（タイトル、説明、チャンネル名、再生時間など）を格納したJSONファイル。動画一覧や機械学習の元データとして利用します。

### manual_classify.csv
動画ごとの手動分類結果（人力で付与したタグやカテゴリ）を保存したCSVファイル。Streamlit分類ページで編集・保存されます。

### ml_feature_info.json
機械学習用特徴量の説明やメタ情報（特徴量名、意味、型など）を格納したJSONファイル。MLモデル構築時の特徴量選択や解釈に使います。

### ml_features.csv
動画ごとの機械学習用特徴量（数値化された情報、埋め込みベクトルなど）を保存したCSVファイル。MLモデルの学習・推論の入力データとして利用します。

### tag_data.json
動画やチャンネルごとに付与されたタグ情報を保存したJSONファイル。タグ管理や検索、分類補助などに使われます。

### watch_later.json
「後で見る」リストの動画IDや関連情報を保存したJSONファイル。未分類動画の抽出や新規動画の管理に利用されます。

---

各ファイルは、YouTube動画の管理・分類・機械学習機能で連携して利用されます。
